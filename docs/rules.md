# 물때마을 규칙 명세 (v1)

이 문서가 게임 규칙의 기준이다. 코드가 이 문서와 다르면 문서가 맞고, 코드를 고친다. 규칙을 바꿀 때는 이 문서를 먼저 고친다.

- **규칙의 형태**(무엇을 세고, 언제 계산하고, 어떤 순서로 진행하는가)는 이 문서가 기준이다.
- **수치의 현재 값**(점수, 물때 주기, 목표, 덱 구성)은 `data/*.json`이 기준이다. 수치를 조정하면 이 문서의 표와 예시도 같이 고친다. 어긋난 것을 발견하면 수치는 json이 맞다.
- 목표 점수, 시작 덱, 묶음 구성은 시뮬레이터로 조정하기 전의 임시값이다(9장).

## 1. 용어

| 용어 | 뜻 |
| --- | --- |
| 칸 | 보드의 한 칸. 좌표는 (x, y)이고 x는 왼쪽부터 0, y는 위부터 0이다 |
| 인접 | 상하좌우 4칸 중 보드 안에 있는 칸. 대각선은 인접이 아니다 |
| 거리 | 두 칸의 가로 차이와 세로 차이를 더한 값(맨해튼 거리) |
| 반경 r | 거리가 1 이상 r 이하인 보드 안의 칸. 반경 1은 인접과 같고, 반경 2는 최대 12칸이다 |
| 건물 | 보드에 놓인 타일 |
| 물 칸 | 지금 물때에서 바다로 보는 칸 (3장) |
| 턴 | 타일 1장을 배치하는 것. 버리기는 턴이 아니다 |
| 손패 | 지금 고를 수 있게 보여 주는 타일. 최대 3장 |
| 덱 | 아직 손패에 나오지 않은 타일의 줄. 위에서 뽑고 아래로 넣는다 |
| 묶음 | 목표를 달성하면 받는 타일 뭉치 |
| 단계 | 지금까지 달성한 목표의 수. 0에서 시작한다 |

## 2. 보드와 지형

- 보드는 직사각형 격자다. 프로토타입 섬은 8×8 안팎이다.
- 지형은 육지(LAND), 갯벌(FLAT), 바다(SEA) 세 가지이고, 판이 진행되는 동안 바뀌지 않는다.
- 한 칸에는 건물을 하나만 놓을 수 있다. 놓은 건물은 없어지거나 옮겨지지 않는다.
- 보드 밖은 칸이 아니다. 인접과 반경 계산에서 빠지고, 바다로 치지도 않는다.

## 3. 물때

- 물때는 썰물(LOW)과 밀물(HIGH) 두 가지다. 썰물로 시작한다.
- 턴이 4번 끝날 때마다 물때가 바뀐다. 1–4번째 턴은 썰물, 5–8번째 턴은 밀물, 9–12번째 턴은 다시 썰물이다.
- 버리기는 턴이 아니므로 물때를 움직이지 않는다. 물때는 타일을 놓을 때만 흐른다.

**물때를 반영한 지형**

| 원래 지형 | 썰물일 때 | 밀물일 때 |
| --- | --- | --- |
| 육지 | 육지 | 육지 |
| 갯벌 | 갯벌 | 바다 |
| 바다 | 바다 | 바다 |

- 배치 조건과 점수 규칙에서 지형을 볼 때는 항상 물때를 반영한 지형으로 본다. 이 판정은 코드에서 한 곳에만 둔다.
- 건물이 있어도 그 칸의 지형 판정은 달라지지 않는다. 염전이 놓인 갯벌도 밀물에는 바다로 본다.
- **물 칸**은 물때를 반영한 지형이 바다인 칸이다. 바다는 항상 물 칸이고, 갯벌은 밀물에만 물 칸이다.

## 4. 타일

프로토타입 타일은 6종이다. 수치는 `data/tiles.json`에서 조정한다.

### 4.1 배치 조건

모든 타일 공통으로, 보드 안의 칸이고 그 칸에 건물이 없어야 한다.

| 타일 | id | 놓을 수 있는 칸 |
| --- | --- | --- |
| 집 | `house` | 육지 |
| 부두 | `pier` | 물 칸과 인접한 육지 |
| 시장 | `market` | 육지 |
| 등대 | `lighthouse` | 육지. 보드에 1개까지 |
| 염전 | `salt_farm` | 갯벌 |
| 덕장 | `drying_rack` | 육지 |

- **부두:** 썰물에는 바다와 인접한 육지에만 놓을 수 있다. 밀물에는 바다나 갯벌과 인접한 육지에 놓을 수 있다.
- **염전:** 밀물에는 갯벌을 바다로 보므로 놓을 수 없다. 썰물에만 놓을 수 있다.
- 갯벌에 놓을 수 있는 건물은 염전뿐이다.
- 배치 조건은 놓는 순간의 물때로 한 번만 검사한다. 나중에 물때가 바뀌어 조건에 맞지 않게 되어도 건물은 남고 점수도 계속 받는다.

### 4.2 배치 점수

타일을 놓는 순간 한 번 계산해 누적 점수에 더한다.

| 타일 | 배치 점수 |
| --- | --- |
| 집 | 인접한 집 1개당 +1<br>인접한 시장이 하나라도 있으면 +2 (여러 개여도 한 번)<br>인접한 물 칸 1개당 +1<br>인접한 덕장 1개당 −1 |
| 부두 | 0 |
| 시장 | 인접한 집 1개당 +2, 인접한 부두 1개당 +2 |
| 등대 | 반경 2 안의 부두 1개당 +3 |
| 염전 | 0 |
| 덕장 | 인접한 부두 1개당 +2<br>인접한 집 1개당 −1 |

### 4.3 물때 점수

물때가 바뀌는 순간, 보드에 있는 해당 건물이 모두 점수를 받는다.

| 타일 | 물때 점수 |
| --- | --- |
| 부두 | 밀물로 바뀔 때 +3, 그 순간 인접한 부두 1개당 −1 |
| 염전 | 썰물로 바뀔 때 +2 |

- 부두 하나가 한 번에 받는 점수는 0–3점이다. 부두는 물 칸과 인접해야 놓을 수 있으므로 인접한 부두는 많아야 3개다.
- 그 턴에 방금 놓은 건물도 전환 점수를 받는다.
- 판을 시작할 때의 썰물은 전환이 아니므로 점수가 없다.

## 5. 점수 계산 원칙

1. **놓는 순간 한 번만 계산한다.** 배치 점수는 놓는 순간의 보드와 물때로 계산한다. 이후 주변에 건물이 생기거나 물때가 바뀌어도 이미 받은 점수는 변하지 않는다.
2. **자기 칸은 세지 않는다.** 인접과 반경은 놓는 타일의 칸을 뺀 주변만 본다.
3. **점수는 음수가 될 수 있다.** 집과 덕장은 음수 점수가 나올 수 있고, 누적 점수가 내려갈 수 있다. 하한은 없다. 이미 달성한 단계는 취소되지 않는다.
4. **물때 점수는 전환 순간의 보드로 센다.** 부두의 인접 부두 수는 물때가 바뀌는 순간의 보드로 센다. 지형을 보는 물때 규칙이 생기면 바뀐 뒤의 물때를 기준으로 한다.
5. **예상 점수는 배치 점수와 같은 계산이다.** 화면에 미리 보여 주는 점수는 실제 배치 점수와 같아야 한다. 물때 점수는 예상 점수에 넣지 않는다.

## 6. 진행

### 6.1 준비

1. 섬 데이터로 보드를 만든다. 물때는 썰물, 턴 수 0, 점수 0, 단계 0이다.
2. 목표는 첫 단계의 목표 점수다.
3. 시작 덱을 섞는다(7장).
4. 손패를 뽑는다.

### 6.2 행동

손패는 덱 위에서 3장을 뽑아 보여 준다. 덱에 3장보다 적게 남았으면 남은 만큼만 보여 준다.

플레이어는 손패가 있는 동안 **배치**와 **버리기** 중 하나를 한다.

**배치 (턴 1회)**

1. 손패 1장과 그 타일을 놓을 수 있는 칸을 고른다.
2. 배치 점수를 계산해 누적 점수에 더하고 건물을 놓는다.
3. 고르지 않은 손패를 손패에 있던 순서대로 덱 아래에 넣는다.
4. 턴 수를 1 올린다. 턴 수가 물때 주기의 배수면 물때를 바꾸고 물때 점수를 누적 점수에 더한다.
5. 목표를 판정한다(6.3).
6. 종료를 판정한다(6.4). 끝나지 않았으면 새 손패를 뽑는다.

**버리기 (턴이 아님)**

1. 손패 1장을 골라 버린다. 그 타일은 판에서 사라지고 점수는 없다.
2. 고르지 않은 손패를 손패에 있던 순서대로 덱 아래에 넣는다.
3. 종료를 판정한다(6.4). 끝나지 않았으면 새 손패를 뽑는다.

- 놓을 수 있는 타일이 있어도 버릴 수 있다.
- 손패에 놓을 수 있는 타일이 하나도 없으면 버리기만 할 수 있다.
- 버리기는 턴 수와 물때를 움직이지 않고, 점수도 바꾸지 않는다.

### 6.3 목표와 묶음

- 누적 점수가 목표 **이상**이면 목표를 달성한 것이다.
- 달성하면 그 목표에 딸린 묶음을 받고, 단계가 1 오르고, 목표가 다음 값으로 오른다.
- 점수가 새 목표에도 닿아 있으면 같은 판정을 반복한다. 한 턴에 여러 단계를 달성하면 묶음도 그만큼 받는다.
- 판정은 턴의 끝에, 물때 점수까지 더한 뒤에 한다.
- 데이터에 적힌 마지막 단계를 지난 뒤에는 목표가 매번 `goal_step`만큼 오르고, 묶음은 `after_last_stage`의 것을 받는다.
- 클리어 조건은 없다. 판은 6.4의 조건으로만 끝난다.

### 6.4 종료

새 손패를 뽑기 전에 검사한다. **남은 타일 가운데 지금 물때에 놓을 수 있는 타일이 하나도 없으면 판이 끝난다.** 덱이 빈 경우도 여기에 포함된다.

- 물때는 배치로만 바뀌므로, 지금 놓을 수 있는 타일이 없으면 앞으로도 없다. 남은 타일을 하나씩 버리는 것과 결과가 같아서 바로 끝낸다.
- 손패에는 놓을 수 있는 타일이 없지만 덱 안에 있다면 판은 끝나지 않는다. 이때는 버리기만 할 수 있다.
- 결과는 최종 점수와 도달한 단계다.

**판은 반드시 끝난다.** 행동마다 타일이 1장 줄어든다. 타일이 늘어나는 것은 목표를 달성했을 때뿐인데, 점수는 배치한 턴에만 오르고 배치 횟수는 보드 칸 수를 넘을 수 없다.

## 7. 덱

- **시작 덱:** 섬 데이터의 `start_deck` 구성을 섞은 것이다.
- **묶음:** 단계마다 구성이 정해져 있다. 받을 때 묶음 안에서만 섞어 덱 아래에 넣는다. 이미 덱에 있던 타일의 순서는 건드리지 않는다.
- **순서:** 한 턴에서 덱 아래로 가는 순서는 고르지 않은 손패가 먼저, 그 턴에 받은 묶음이 다음이다. 묶음을 여러 개 받으면 먼저 달성한 목표의 묶음이 먼저다.
- **무작위:** 섞기는 판의 seed로 만든 난수 생성기 하나만 쓴다. 같은 seed로 같은 행동을 하면 같은 판이 된다.

## 8. 예시

아래 값은 v1 수치로 계산한 것이며, 규칙을 그대로 옮긴 임시 계산 스크립트로 검산했다. 단위 테스트의 기대값으로 쓸 수 있다. 격자에서 L은 육지, F는 갯벌, S는 바다다.

### 예시 1. 집과 시장

```
x:  0 1 2 3
    L L L L      썰물
```

| 순서 | 놓는 것 | 점수 | 이유 |
| --- | --- | --- | --- |
| 1 | 집 (0,0) | 0 | 주변에 아무것도 없다 |
| 2 | 집 (1,0) | +1 | 인접한 집 1개 |
| 3 | 시장 (3,0) | 0 | (2,0)이 비어 있어 인접한 집과 부두가 없다 |
| 4 | 집 (2,0) | +3 | 인접한 집 1개(+1), 인접한 시장(+2) |

합계는 4점이다. 2번에 놓은 집은 4번 뒤에도 +1 그대로다. 같은 자리에 집 3개를 먼저 놓고 시장을 마지막에 놓으면 0, +1, +1, +2로 합계가 같다.

### 예시 2. 시장이 여러 개여도 +2는 한 번

3×3이 모두 육지이고 시장이 (1,0)과 (0,1)에 있다. 집을 (1,1)에 놓으면 +2다.

### 예시 3. 집의 물 칸 점수는 물때에 따라 다르다

```
x:  0 1 2
    S L F
```

집을 (1,0)에 놓으면 썰물에는 +1(바다 1칸), 밀물에는 +2(바다 1칸과 갯벌 1칸)다. (2,0)에 염전이 있어도 밀물에는 +2다.

### 예시 4. 부두와 염전의 배치 조건

```
x:  0 1 2 3
    L L F S
```

| 타일 | 칸 | 썰물 | 밀물 |
| --- | --- | --- | --- |
| 부두 | (1,0) | 불가. 인접한 물 칸이 없다 | 가능. 갯벌이 물 칸이다 |
| 부두 | (0,0) | 불가 | 불가 |
| 염전 | (2,0) | 가능 | 불가. 갯벌을 바다로 본다 |
| 염전 | (1,0) | 불가. 육지다 | 불가 |
| 집 | (2,0) | 불가. 갯벌이다 | 불가 |

밀물에 (1,0)에 놓은 부두는 썰물이 되어도 남고, 밀물로 바뀔 때마다 +3을 받는다.

### 예시 5. 부두의 물때 점수

```
x:  0 1 2 3 4
    S S S S S    y=0
    L L L L L    y=1
```

- 부두가 (0,1), (1,1), (2,1)에 붙어 있으면 밀물로 바뀔 때 2 + 1 + 2 = 5점이다.
- 부두가 (0,1), (2,1), (4,1)에 한 칸씩 떨어져 있으면 3 + 3 + 3 = 9점이다.
- 떨어져 있는 배치에서 (1,1)에 시장을 놓으면 +4(인접한 부두 2개), (3,1)에 덕장을 놓으면 +4다.

### 예시 6. 등대의 반경 2

```
x:  0 1 2 3 4
    S S S S S    y=0
    L L L L L    y=1
    L L L L L    y=2
```

y=1 줄 5칸에 모두 부두가 있을 때 등대를 (2,2)에 놓으면 +9다. 거리 1인 (2,1), 거리 2인 (1,1)과 (3,1)의 부두 3개를 센다. (0,1)과 (4,1)은 거리가 3이라 세지 않는다. 등대가 이미 있으면 두 번째 등대는 어디에도 놓을 수 없다.

### 예시 7. 집과 덕장의 감점은 순서와 상관없다

```
x:  0 1 2
    L L L
```

- 덕장을 (1,0)에 먼저 놓고 집을 (0,0)에 놓으면 집이 −1이다.
- 집을 (0,0)에 먼저 놓고 덕장을 (1,0)에 놓으면 덕장이 −1이다.

### 예시 8. 물때 시간표

| 턴 | 1–4 | 5–8 | 9–12 |
| --- | --- | --- | --- |
| 물때 | 썰물 | 밀물 | 썰물 |

- 4번째 턴의 배치가 끝나면 밀물로 바뀌고 부두가 점수를 받는다. 4번째 턴에 놓은 부두도 +3을 받는다.
- 8번째 턴의 배치가 끝나면 썰물로 바뀌고 염전이 점수를 받는다.
- 중간에 타일을 몇 장 버려도 턴 수와 물때는 그대로다.

### 예시 9. 손패와 덱의 순서

덱이 위에서부터 [부두, 집, 시장, 염전, 덕장]이면 손패는 [부두, 집, 시장]이다.

1. 집을 배치한다. 부두와 시장이 순서대로 덱 아래로 간다. 덱은 [염전, 덕장, 부두, 시장]이 되고 다음 손패는 [염전, 덕장, 부두]다. 턴 수는 1이다.
2. 이어서 염전을 버린다. 덕장과 부두가 덱 아래로 간다. 덱은 [시장, 덕장, 부두]가 되고 다음 손패는 [시장, 덕장, 부두]다. 턴 수는 1 그대로다.

### 예시 10. 한 턴에 여러 단계

목표가 10, 24, 42 순서일 때 점수 8에서 한 턴에 17점을 얻어 25점이 되면 10과 24를 모두 달성한다. 단계는 2가 되고 목표는 42가 된다. 목표 10에 딸린 묶음과 목표 24에 딸린 묶음이 이 순서로 덱 아래에 들어간다.

### 예시 11. 종료

- 남은 타일이 염전뿐인데 4번째 턴이 끝나 밀물이 되었다. 놓을 수 있는 타일이 없으므로 판이 끝난다. 빈 갯벌이 남아 있어도 마찬가지다.
- 남은 타일이 두 번째 등대뿐이다. 판이 끝난다.
- 밀물이고 손패 3장이 모두 염전이지만, 덱에 집이 있고 빈 육지가 있다. 판은 끝나지 않는다. 손패 중 1장을 버려야 한다.
- 마지막 타일을 놓았는데 점수가 목표에 못 미친다. 덱이 비었으므로 판이 끝난다.
